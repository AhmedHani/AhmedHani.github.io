This is my last post of the year — a Java implementation of the Hidden Markov Model API, built to complement the [HMMs Part I](/2015/10/25/hidden-markov-models-hmms-part-i/) theory post.

The project is designed to be clean and easy to use. It is not the final version; further enhancements are planned and will be documented in the repository README.

The test model used is the weather/health HMM from Part I, created with [creately.com](http://creately.com):
